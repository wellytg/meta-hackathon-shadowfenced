Shadowfenced test page (local demo)

This page imitates a chat composer so the extension can be demonstrated without logging into any real site. Serve it with python -m http.server 8000 from extension/testpage, open http://127.0.0.1:8000/index.html, and load the dev build (python extension/build.py --dev). Type something sensitive, hover the underline, then press send.
