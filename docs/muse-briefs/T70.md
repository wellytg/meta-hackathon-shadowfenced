## Order of sections

1. **Title + one-paragraph pitch.** Lead with impact: many companies ban or restrict cloud AI because staff paste
   customer data, contracts and keys into it. Shadowfenced is a local guard that lets them allow it: sensitive text
   is stopped or replaced with placeholders on the person's own PC before any AI sees it, and answers come back with
   the real values restored locally. Who benefits: staff who use AI chats and coding agents, and the security teams
   who have to approve them.
2. **Links line:** `▶ Demo video: VIDEO_URL` (leave this exact placeholder; it is filled after upload) · `Live demo:
   https://wellytg--shadowfenced-asgi.us-east.modal.run` (fictional data only; hosted mode, see below).
3. **What it does** (short bullets, each verified in code): underlines as you type; blocks keys and planted canaries
   in any encoding; placeholders + local restore (`[PII_EMAIL_1]`, `redact.rehydrate`); full identity bundle (name +
   date of birth + address + phone/email) → BLOCK with no model call; person-search intent asks first; browser
   extension on ChatGPT and Gemini; **file guard** (files stopped before upload, scanned locally, bank statements /
   secrets / bundles cannot be uploaded as-is, one-click redacted copy keeping CSV/JSON structure, optional Glimmer
   deep check); OpenAI-compatible proxy for CLI agents and SDKs (`/v1/chat/completions`, every message role checked,
   real keys fingerprinted); screenshot redaction (opt-in, Glimmer regions + SAM 3.1 masks); Muse Voice dictation and
   audio-upload transcription; a hash-chained decision log that never stores values.
4. **How a message is decided** — keep the existing tier diagram/section, updated: Tier 1 code → Tier 2 Muse Glimmer
   30B on this PC → Tier 3 code verifies the model's claim → Tier 4 the person. Precedence BLOCK > HOLD > REDACT >
   WARN > ALLOW; fails closed. Add: a model verdict can never downgrade a code finding, and text aimed at the safety
   check is held (T68).

   - Muse Voice — dictation and audio-upload transcription — Meta Model API.
