# T84 — Other extensions and browser assistants can read the page (disclose, plan, notify)

Branch `docs/beyond-hackathon` (checked out; it already has SECURITY.md, CONTRIBUTING.md, docs/ROADMAP.md from
T82). Small change. Do not touch README.md, `src/`, or anything outside the files named here. Do not commit;
leave changes in the working tree and print a summary.

Fact to communicate: any other browser extension that has access to an AI chat site (and built-in browser
assistants such as Gemini in Chrome or Copilot in Edge, which are not extensions) can read what a person types
on that page before Shadowfenced acts. Shadowfenced cannot block that today.

1. `SECURITY.md`, in the browser extension notes: one short paragraph stating the fact above as a known limit,
   and how to check: Chrome/Edge extension details → Site access.
2. `docs/ROADMAP.md`: add an item "Extension watch": list installed extensions that can read AI chat sites and
   warn about them (needs the `management` permission, which shows an install warning, so it would be opt-in);
   built-in browser assistants cannot be detected by an extension; blocking or disabling other extensions is
   out of scope without the person's explicit choice. Keep the roadmap about one screen.
3. `extension/src/popup.html` (+ `extension/src/styles.css` if needed): add one small static notice at the
   bottom of the popup, no new permission, no script: "Other extensions and built-in browser assistants with
   access to this site can also read what you type. Check Site access in your browser's extension settings."
   Match the popup's existing style. Do not change `manifest_*.json` permissions.
4. Run `node --check` on any changed JS (there should be none), the extension tests if they exist
   (`extension/tests/`), and the Python suite (deselect the two timing tests); all must pass.
