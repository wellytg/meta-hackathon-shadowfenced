T14 corpus (corpus/cases.yaml + src/shadowfenced/corpus.py):
- ~40 cases: 10 secrets, 7 PII, 4 business, 3 beacons, 16 benign look-alikes (>= 40% benign), as listed in the plan.
- The YAML holds templates only, never secret values: {{canary:<kind>}}, {{canary:<kind>|base64|hex|rot13|reversed|url|split}},
  {{fake_key:<provider>}} (prefix built in code from fragments, rest from a seeded RNG), {{entropy:32}},
  {{file:<name>}} (generated at runtime like scripts/make_files.py). Fictional org Corvane Labs only.
- Case schema: {id, category, input or file, expect: ALLOW|REDACT|BLOCK|HOLD, acceptable: [..], classes: [..],
  sensitive_values: [template refs]}. Beacons expect HOLD (acceptable REDACT). Generic entropy token: expect HOLD.
T15 evaluation (scripts/eval.py):
- `python scripts/eval.py --judge glimmer|llama|none [--limit N]` runs every case in process through engine.gate in
  send mode; for HOLD cases also runs holds.run_review synchronously (judge per flag: glimmer -> muse-glimmer:30b,
  llama -> llama3.2:3b, none -> SF_TIER2_MODE=off) and records the final outcome after review.
- Upstream is a dry capture (no network): record the exact outbound payload.
- Metrics: leak_rate (sensitive cases whose captured outbound payload contains any sensitive value in any encoded
  form, / sensitive cases; HOLD-needs_human and BLOCK count as not leaked), catch_rate, false_escalation_rate
  (benign cases with final outcome != ALLOW / benign), hold_rate, human_rate (needs_human share),
  resolved_by_tier shares (1, 3, 4), latency_ms per tier p50/p95/max, per_case rows, config {judge, models, seed,
  git sha, date}.
- Writes runs/eval_<YYYY-MM-DD>_<judge>.json and prints a compact table. Unload nothing; use keep_alive 5m (not -1)
  for eval runs to avoid pinning memory.
