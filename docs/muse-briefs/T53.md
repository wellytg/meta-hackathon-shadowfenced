# T53 — Make the local Glimmer checks finish on a 12 GB GPU instead of timing out

Measured on the owner's PC (Muse Glimmer 30B Q4, 9.3 of 17 GB in VRAM, rest on CPU; about 8 tokens/s; Ollama runs one
request at a time):
- `person_search.local_glimmer_person_search(...)` on the Dana Whitlock people-search example: with the default 10 s
  timeout it returns None ("Glimmer could not check intent"); with 60 s it returns the right answer in 19.3 s.
- A bare "Say OK" chat call with the shared options takes about 2 s, so most of the time is generation length and
  prompt size, not loading.
- "Summarise the life of Ada Lovelace, born 10 December 1815 in London." ends as HOLD with only the reason
  "sensitivity cue word needs Glimmer review -> HOLD": the cue-word judge also times out, so the gate fails closed.

Fix (keep fail-closed behaviour; read `judge.py`, `person_search.py`, `reid.py`, `glimmer.py`, `engine.py`):
1. One setting `SF_GLIMMER_TIMEOUT_S` (default 45) used by every local Glimmer text call via the shared helper,
   replacing the scattered 10 s defaults; image calls keep their own longer setting.
2. Make answers short: smallest JSON schema that carries what the code uses; `num_predict` sized to that schema
   (person-search: subject, person_search, subject_public, up to 5 short inferred items); trim system prompts; cap user
   text sent to Glimmer at what the check needs.
3. Avoid duplicate Glimmer calls on one send: if the cue-word judge, person-search and residual check would all run,
   run them in a fixed order and skip later ones when an earlier result already decides the outcome (document the
   order in `docs/ARCHITECTURE.md`).
4. The UI already shows "Checking locally…"; make the status line say "Muse Glimmer is checking on this PC…" after 2 s.
5. Tests with mocked transports: timeout setting is honoured everywhere; schema/num_predict per call; skip logic.
   Add `scripts/time_glimmer.py` that times each real Glimmer check on three synthetic messages (owner runs it).
   Run `python -m pytest -q -p no:cacheprovider` and `python scripts/ci.py`. Do not commit.
