T12 Upload:
- extract.py: txt, md, csv, docx (python-docx), pdf (pypdf) -> text; max 2 MB; errors -> status "unscannable".
- POST /api/upload (multipart `file`) -> {file_id, name, kind, chars, status clean|flagged|unscannable, spans,
  summary{pii:n,...}}; unsupported type -> 415. Store extracted text in memory by file_id (TTL 15 min).
- /api/send accepts file_ids: each file's text is gated with the message (combined decision; redaction placeholders
  shared); upstream receives the message plus "Attached file <name>:\n<redacted text>". Unscannable file -> HOLD.
- UI: paperclip button + `file-input`; a `file-chip` (data-status) above the composer showing name, icon and summary
  ("3 email addresses, 1 client name"); click the chip to list its findings; x to remove.
- scripts/make_files.py: writes synthetic demo files to runs/files/ at runtime: customers.csv (8 rows fictional
  names, example-free emails @corvane.io, phones), roadmap.docx (mentions Project TALLOW and client Aster Freight),
  notes.md (benign), memo.pdf (one runtime canary line). Use only fictional data.
