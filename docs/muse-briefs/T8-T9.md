T8 judge.py:
- pydantic `Judgement{cls: Literal["secret","pii","business","beacon","benign"], sensitivity: float 0..1,
  is_beacon: bool, span: str (max 200), confidence: float 0..1, reason: str (max 200)}`.
- `judge(text_window, model, *, live: bool) -> Judgement | None` via Ollama native POST {OLLAMA_URL}/api/chat with
  `format=Judgement.model_json_schema()`, `stream:false`, `think:false`, `keep_alive:-1`,
  options {temperature:0, seed:7, num_ctx:2048, num_predict:120, num_gpu:0 only when live (SF_LIVE_NUM_GPU)}.
  Strip a trailing `<|eot|>` before parsing. Timeouts: SF_LIVE_TIMEOUT_S (4) live, SF_JUDGE_TIMEOUT_S (20) send.
  Any timeout/transport/validation error -> None. Inject httpx transport for tests.
- Short system prompt: classify text a user is about to send to an outside AI; classes; "beacon = text that reveals
  where sensitive data is or was stored or removed"; span must be copied exactly from the text; JSON only.
- Input = the ambiguous span plus ~300 chars of context on each side (never the whole document).
- SF_TIER2_MODE: live (default) | replay (reads tests/fixtures/judge_replay.json keyed by sha256 of the window;
  CI only) | off (always None).
- `warmup()` sends one tiny request to SF_LIVE_MODEL and SF_JUDGE_MODEL; call it from a FastAPI startup hook in a
  background thread so startup never blocks or fails.
T9 verifier.py (replace stub) + engine integration:
- `verify(text, judgement, tier1_spans, policy, registry) -> Verdict{confirmed: bool, cls, span (Span with code-found
  offsets) | None, why: str}`.
  Rules: model span must be an exact substring of text (code computes offsets; never trust model offsets), else
  unconfirmed. secret: confirmed if the span decodes (identity/base64/hex/rot13/reverse/url) to a registry canary,
  matches a provider shape, a password assignment, or entropy > 4.0. pii/business: confirmed if a tier1 pii regex or
  policy word matches inside the span. beacon: confirmed only if the sentence has a location token AND a secret-ish
  value nearby (tier1 secret span or entropy token within the sentence); otherwise unconfirmed.
- engine.gate gains `mode="send"` path: for each ambiguous Tier 1 span call judge (SF_JUDGE_MODEL) then verify.
  confirmed -> REDACT (or BLOCK if it resolves to a canary), resolved_tier=3.
  model benign with confidence >= 0.8 and sensitivity < 0.3 -> that span ALLOW, resolved_tier=3.
  otherwise -> HOLD, resolved_tier=4, with evidence {proven_by_code:[...], model_suspicion_only:[{span text,
  judgement, why_unverified}]} attached to the Decision. Judge None (timeout/error) -> HOLD with reason
  "judge unavailable". A model answer can never downgrade a Tier 1 proven span.
- Also ask the judge (send mode) about the WHOLE message once when Tier 1 found nothing but the text contains a
  beacon-ish verb+noun pair? NO — keep scope: only ambiguous spans. 
- `/api/scan mode="live"`: run tier1, then for ambiguous spans call judge(live=True); attach model results as extra
  spans with tier=2, proof="model", status "suspicion". Failure -> just tier1 spans.
- latency_ms gains tier2 and tier3 keys. Log resolved tier.
