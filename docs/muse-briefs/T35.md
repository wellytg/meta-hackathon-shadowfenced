# T35 — Connect a provider with API keys (Meta first)

Read `design-ref/PROVIDERS.md` (research on each provider's official options) before starting.

1. **Provider registry** in `src/shadowfenced/providers.py`: Meta Muse Spark (default, listed first), OpenAI,
   Google Gemini (its OpenAI-compatible endpoint), Anthropic Claude (its OpenAI-compatible endpoint if documented in
   PROVIDERS.md, otherwise its Messages API), OpenRouter, and local Ollama. Each entry has: id, label, base URL,
   default model, "Get a key" URL, and whether it needs a key. Forwarding keeps going through the existing gated path:
   only clean or redacted text is ever sent, whichever provider is chosen.
2. **Key storage**: store keys in the operating system's credential store via the `keyring` package (Windows
   Credential Manager, macOS Keychain, Linux Secret Service); fall back to the existing `.env` settings only when no
   keyring backend exists, and say so in the UI. Keys are never returned by any endpoint, never logged, never put in
   traces, and every stored key is added to the protected-key fingerprints (`keyguard.py`) so it can never be sent
   upstream inside a message.
3. **Endpoints**: `GET /api/providers` (adds `connected: bool`, `needs_key`, `get_key_url`), `POST
   /api/providers/{id}/key` (store), `DELETE /api/providers/{id}/key`, `POST /api/providers/{id}/test` (one tiny
   request, returns ok/error text only). OpenRouter: OAuth with PKCE exactly as described in PROVIDERS.md, with the
   callback on 127.0.0.1, storing the returned key the same way. In hosted demo mode, storing keys is disabled.
4. **UI**: new `src/shadowfenced/static/providers.js` and `providers.css` (one tag each in index.html) that fill
   `#providers-panel` if present (otherwise open their own dialog from a "Providers" button): one card per provider
   with status, "Get a key" link (opens the official page), a password-type paste field, Save, Test connection,
   Disconnect, and for OpenRouter a "Log in with OpenRouter" button. Text explains: "Your key stays on this computer.
   Shadowfenced only sends checked, redacted text to the provider you pick."
5. Tests with fake transports and a fake keyring: keys never echoed or logged, keyguard learns stored keys, test
   endpoint errors are clean, PKCE verifier/challenge correct, hosted mode refuses storage. Add `keyring` to
   dependencies. Run `python -m pytest -q`. Do not commit. No network.
