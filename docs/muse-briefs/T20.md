# T20 — Splash page and visual refresh (no behaviour change)

Design direction: crisp, simple and unlike typical AI-generated sites. Light first: warm off-white paper
background, near-black ink, ONE signal colour (safety orange, about #FF5A1F) for danger/blocked, and one cool steel
blue for safe/allowed. No gradients, no glassmorphism, no neon glow, no purple, no emoji, no generic grid of
identical rounded cards, no centred-everything hero. Hard 2px ink outlines, flat fills, bold grotesk display type,
monospace for data, a strong grid with generous whitespace, like printed event collateral. "Crisp 3D" means
flat-shaded ISOMETRIC illustration drawn in SVG (three tones per face, crisp edges): a fence of isometric blocks
between a laptop (left) and a cloud (right), with a small tag labelled [PII_EMAIL_1] passing through the fence while
the real value stays on the laptop side. System font stacks only (no web fonts, no network).

Files you own: `src/shadowfenced/static/style.css` (restyle), new `src/shadowfenced/static/welcome/index.html`,
new `src/shadowfenced/static/welcome/welcome.css`, new SVGs under `src/shadowfenced/static/assets/`, and a new test
file `tests/test_welcome_page.py`. You may make small edits to `src/shadowfenced/static/index.html` (class names, a
header link to `/welcome/`), nothing else in it.

Hard rules:
- Do not edit `app.js`, any Python under `src/`, or existing tests. The console must keep working at `/`.
- Keep every element id and every `data-testid` in index.html, and keep the DOM structure app.js relies on. These
  test ids are used by demo recorders and must stay present, visible and clickable: composer, send, answer, banner,
  btn-why, btn-approve, btn-deny, evidence-card, file-input, ai-saw-toggle.
- Status colours must stay distinguishable: blocked, redacted, held, allowed.

1. Splash page at `/welcome/` (served by the existing static mount): one screen that explains the product in plain
   words, the isometric fence illustration (inline SVG), three short points (underlines as you type; only clean or
   redacted text leaves; real values come back on your machine), and a clear "Open the console" link to `/`. Works
   at 400px wide. Respect prefers-reduced-motion if you animate anything.
2. Restyle the console (style.css) in the same design language so the splash and console feel like one product.
3. `tests/test_welcome_page.py`: `/welcome/` returns 200 and links to `/`; index.html still contains every test id
   listed above.
4. Use your built-in taste skill before styling. Run `python -m pytest -q` and report. Do not commit.
