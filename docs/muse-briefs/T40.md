# T40 — Architecture map and a live component status panel

Goal: anyone (a judge, a contributor) can see the moving parts at a glance and tell which part is failing.

1. `docs/ARCHITECTURE.md` with Mermaid diagrams that GitHub renders:
   - **Request path**: person (chat app), browser extension, coding agent (OpenAI-compatible proxy) → Shadowfenced on
     this PC → chosen AI provider; and the answer path back with local restore.
   - **Decision pipeline**: Tier 1 code detectors (canaries and encodings, provider key shapes, protected-key
     fingerprints, PII, bank details, documents, business policy, beacons, custom rules) → re-identification scoring →
     Muse Glimmer (local judge, person-search intent, residual inference check) → Tier 3 code verification → person;
     precedence BLOCK > HOLD > REDACT > WARN > ALLOW; fail-closed paths.
   - **Modules**: one box per Python module and static script with a one-line job, and which Meta model it uses
     (Muse Glimmer local, Muse Spark upstream / hosted judge, Muse Voice transcription, Llama 3.2 local stand-in),
     plus the hash-chained log and the local key store.
   - **How it was built**: the Muse Code agent workflow (brief → agent in a key-free clone → tests outside the sandbox
     → PR with CI → merge), and which tasks (T1–T42) built which module, read from `docs/muse-briefs/` and git log.
2. `GET /api/health/components`: for each component return `{name, status: ok|degraded|down|off, detail}` using cheap
   local checks only (Tier 1 self-test on a built-in canary, Ollama reachable and Glimmer listed, Meta key present
   without revealing it, Muse Voice configured, keyring backend available, log chain verified, extension pairing set,
   hosted mode on/off). Never call a paid API from this endpoint.
3. A "System status" section in the details drawer that shows those components with text labels (OK / Degraded /
   Down / Off) in the existing square Classic style, refreshed when opened.
4. Tests: the endpoint never returns secrets, each check's failure maps to the right status, no network calls.
   Run `python -m pytest -q`. Do not commit.
