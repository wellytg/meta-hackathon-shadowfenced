# T19 — Continuous integration and licence

1. Add `.github/workflows/ci.yml`: runs on push and pull_request; ubuntu-latest; Python 3.11 and 3.12 matrix;
   `pip install -e ".[dev]"`; `python -m pytest -q`. No secrets, no network calls in tests.
2. Add `scripts/ci.py`, a local gate that runs, in order, and exits non-zero on any failure:
   (a) `python -m pytest -q`; (b) `python -m compileall -q src scripts`; (c) a scan of every git-tracked file for
   real provider key shapes and for a tracked `.env` (reuse the approach in `tests/test_repo_guard.py`: build the
   prefixes from fragments so the script itself contains no key-shaped literal). Print a one-line PASS/FAIL summary.
3. Add a `LICENSE` file with the full, unmodified Apache License 2.0 text (copyright line: "Copyright 2026 Shadowfenced").
4. Do not change any other file. Run `python scripts/ci.py` and report the result. Do not commit.
