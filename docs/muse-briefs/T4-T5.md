T4 (src/shadowfenced/redact.py, engine.py):
- Decision dataclass: decision ALLOW|REDACT|BLOCK|HOLD, decision_id (uuid4 hex), spans, sent_text (None unless sent),
  placeholders map (server-side only), resolved_tier, latency_ms dict, reasons.
- engine.gate(text, policy, registry, choices=None) -> Decision. Severity BLOCK > HOLD > REDACT > ALLOW.
  canary -> BLOCK; other proven secret, pii, business -> REDACT (action from policy); ambiguous -> HOLD (Tier 2 comes later).
  choices [{span_id, choice: redact|keep}]: keep only if policy user_can_keep for that class (never secret); log reason.
  Any exception inside gate -> HOLD with reason "internal_error" (fail closed).
- redact.py: placeholders numbered per class: [SECRET_1], [PII_EMAIL_1], [PII_PHONE_1], [CODENAME_1], [CLIENT_1],
  [FIGURE_1], [BEACON_1]; same value -> same placeholder. rehydrate(answer, mapping) tolerant to case/spacing/_/-
  (regex in plan), returns (text, highlights[{start,end,placeholder}], unmatched[]).
- In-memory store of mappings per decision_id with 15 min TTL.

T5 (src/shadowfenced/config.py, upstream.py, app.py):
- config: pydantic settings from env / .env (read .env with a tiny parser; never print values). OLLAMA_URL default
  http://127.0.0.1:11434. SF_UPSTREAM default "ollama" when META_API_KEY empty, else "meta". META_BASE_URL and
  META_MODEL from env (defaults empty -> treat Meta as unavailable).
- upstream.py: async `chat(messages, provider)` via httpx to an OpenAI-compatible /v1/chat/completions
  (Ollama: {OLLAMA_URL}/v1/chat/completions with SF_LOCAL_UPSTREAM_MODEL; Meta: {META_BASE_URL}/chat/completions with
  Bearer META_API_KEY). Timeout 60 s. Raise UpstreamError on failure. Allow injecting an httpx transport for tests.
- app.py FastAPI: POST /api/scan {text, mode} -> spans (Tier 1) + latency_ms; POST /api/send per contract
  (gate the concatenated user text, forward REDACT/ALLOW text, rehydrate answer); POST /v1/chat/completions per contract
  (200 + shadowfenced field + X-Shadowfenced-Decision header; BLOCK 403 shadowfenced_block; HOLD 409 shadowfenced_hold;
  stream=true -> one SSE chunk then [DONE]; upstream error -> 502 shadowfenced_upstream; non-text content parts -> HOLD);
  GET /api/health. Mount static/ at / if the folder exists. main() runs uvicorn on 127.0.0.1:8765.
