# T43 — Screenshot redaction with Muse Glimmer + SAM 3.1 (opt-in)

Someone attaches a screenshot or photo (PNG/JPEG) that shows an email, a name badge, a card number, a key on a terminal
screen. Flow: **Muse Glimmer (local, Ollama model `muse-glimmer:30b`, vision capable) looks at the image and lists the
sensitive regions as text prompts or boxes → SAM 3.1 (Meta Model API, model `sam-3.1`, served through the Responses
API; output decoded with the `meta-sam-parser` package) turns them into exact masks → code fills the masks solid black,
and only the redacted image may be sent.** Read `extract.py`, `uploads.py`, the upload routes in `app.py`, `hosted.py`,
`upstream.py` (how the Meta key is read; never print it) and `config.py` first. Look up the current SAM 3.1 Responses
API request shape and the meta-sam-parser output format in their public docs before coding.

1. `image_redact.py`: `find_regions(image)` (Glimmer, local; any text Glimmer reads back also goes through the Tier 1
   detectors), `segment(image, regions)` (SAM 3.1), `apply_masks` (Pillow, solid black, strips EXIF/metadata). If SAM is
   off or fails, fill the boxes instead (fail closed: never send the original when a region was found).
2. Opt-in: setting `image_redaction` off by default. When the user first attaches an image with it off, show a notice
   card: "Images are checked on this PC by Muse Glimmer. Exact masks use Meta SAM 3.1 in the cloud, which receives the
   original image." Choices: Turn on / Keep images local (box fill only) / Don't attach. Store the choice in settings.
3. UI: the attachment chip shows a thumbnail of the redacted image and "N regions hidden"; clicking shows before/after
   side by side locally. Square Classic style, no rounded corners.
4. Hosted mode (`SF_HOSTED=1`): image redaction is off (no local Glimmer); attaching an image returns a clear message.
5. Tests with synthetic images drawn in the test (Pillow writes a fake email and a fake key on a white canvas): mocked
   Glimmer and mocked SAM (httpx MockTransport and a fixture string in the parser's format); fallback path; metadata
   stripped; consent required; hosted mode refuses. No real network in tests. Add `scripts/try_image_redact.py <png>`
   for a real run outside the sandbox. Add Pillow and meta-sam-parser to dependencies (import meta-sam-parser lazily so
   the app still starts without it). Run `python -m pytest -q`. Do not commit.
