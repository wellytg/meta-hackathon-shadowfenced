# T42 — Browser extension: look finished, behave clearly

Keep the square Windows 3.11 style (hard 2px outlines, paper background, ink text, safety orange blocked, steel blue
allowed, amber review, system fonts, no rounded corners). Read `extension/README.md` and the extension code first.

1. **Popup**: a title bar "Shadowfenced", a status row with a text label and icon (Connected · checking locally /
   Not running — start Shadowfenced / Not paired — paste your token), the pairing field with Paste and Save, per-site
   on/off switches for chatgpt.com, claude.ai, gemini.google.com and meta.ai, and a "Test" button that checks a
   sample text through the local app and shows the result. Width about 340px.
2. **In-page cards** (inside the closed shadow root): the hover card for an underline (what was found, "Replace with
   placeholder", "Ignore"), the send-time card (Blocked — not sent / N details protected / Review: reason with "Send
   anyway" and "Cancel"), and the not-running card. Each card has a title bar, plain text, keyboard focus, Escape to
   close, and never covers the site's send button permanently.
3. **Underlines**: wavy or dotted lines in the state colour that line up with the text while typing, scrolling and
   resizing; they disappear when the text is fixed.
4. **Icons**: make the 16/32/48/128 px extension icons as simple square pixel-style artwork (SVG source plus PNGs
   generated by a small Python script in the repo, no external tools).
5. **Local test page** `extension/testpage/index.html`: a page that imitates a chat composer (textarea and a
   contenteditable variant, a send button and a reply area) so the extension can be demonstrated and tested without
   logging into any real site; add it as an extra match pattern only in a separate dev build (`build.py --dev`), not
   in the release manifest.
6. Update `extension/README.md` with screenshots placeholders and install steps. Tests for build output (release
   manifest has only the four sites + 127.0.0.1; dev build adds the test page), icons present at all sizes.
   Run `python -m pytest -q`. Do not commit.
